## 2. 見つけて直した実在の欠陥

### ① 通期ガイダンスを翌四半期コンセンサスと比較していた

決算の質を評価する処理（`hawkeye/scout/quality.py` の `_guidance_leg`）が、会社の示した
見通しの**期間を確認せずに**翌四半期の予想と突き合わせていました。

ADMの実データ（通期EPS $5.15〜$5.60 / 翌四半期コンセンサス約$1.20）で再現したところ、
**+347.9% のガイダンス上振れ**という、会社が一度も言っていない数字が出ました。
上振れは加点なので、これは**候補を上位に押し上げる方向の欠陥**です。

これまで表面化しなかったのは、ガイダンスの取得経路が閉じていて実データが0件だったから。
**EWを繋いだ瞬間に効き始める**欠陥でした。修正後は、期間が翌四半期でない見通しは
「比較していない」と理由つきで記録します（日本語レポートにも文言を追加）。

### ② 見通しの期間ラベルが無い記録の扱い

期間ラベルの無いガイダンス（エージェントが `var/releases/` に置いた既存の読み取り）は
従来どおり「翌四半期のもの」として扱います。これを拒否すると、いま持っている
ガイダンスが全部落ちるためです。テストで固定済み。

## 3. 方針変更として記録すべきこと（ユーザー承認済み）

### 「上振れは2ソース一致のときだけ」規則の緩和

EWを唯一の数値源にすると、コンセンサスは常に1ソースになります。従来のコードでは
1ソースのコンセンサスは無条件に「未検証」となり、**全銘柄・全柱が未検証＝推奨永久ゼロ件**
になります。ユーザー判断により、1ソースのコンセンサスでも上振れを認めるよう変更しました
（`config.earnings_single_source_consensus_blocks = False`、既定オフ）。

**失ったもの**：ベンダーが自分自身と矛盾するコンセンサスを返すケース（BJRI 2026-07-30 に
実在）を、ベンダー間比較で機械的に検出することはできなくなりました。フラグ
（`single_source_consensus`）は柱に残り、審理にも日本語レポートにも表示されます。
規則を戻すのは config の1行です。

## 5. リスクと未確認事項（Transparent）

### ① 【要対応・設計上の不整合】数値の出所を表す欄の名前が実態と合わない

決算内容の器（`EarningsPrint`）とコンセンサスの器（`ConsensusSnapshot`）は、数値の欄が
**`_yahoo` と `_finnhub` という2つのベンダー名で固定**されています。EWの数値をこのどちらかの
欄に入れると、台帳にも日本語レポートにも「Yahooの数字」「Finnhubの数字」として表示され、
**実際にはEWの数字なのに別のベンダー名が表示される**ことになります。

これは今回直したガイダンスの虚偽表示と**同じ種類の欠陥**なので、配線より先に直します。
必要なのは、契約に出所中立（または `whispers`）の欄を足し、評価処理と日本語レポートの
表示をそれに合わせることです。**この不整合があるため、scout本体への配線は意図的に
着手していません**（中途半端に繋ぐと、出所を偽った数字が台帳に入るため）。

### ② EWのレート制限・利用規約が未確認

- 0.4秒間隔の連続54リクエストは問題なく通った（今回の採取で実測）。それ以上は未測定
- 1走査で最大200件（`config.scout_max_whispers`）を想定しているが、**実行して測っていない**
- 商用サイトの利用規約は未確認。継続的な自動取得の可否は未判断

### ③ ガイダンス抽出のカバー範囲は「47銘柄で見えた形」に限られる

fixtureの全銘柄でパーサが破れないことはテストで固定していますが、これは
**2026-08-05に採取した47銘柄に現れた文型**の話です。未知の文型が来たときは
`unparsed_clause` として記録され、テスト（`test_no_recorded_response_defeats_the_guidance_parser`）
が次の採取時に落ちる形にしてあります。**黙って落ちることはない**が、**取りこぼしはあり得る**。

### ④ 48時間という長さ自体は未検証

EWの実績反映が「約1日遅れ」であることは16件で実測しましたが、
**48時間で足りるか（それとも長すぎるか）は、保留の実データが溜まるまで分かりません**。
`config.earnings_actual_wait_hours` の1行で変えられます。

### ⑤ 非12月決算の会計四半期は2銘柄でしか確認していない

`q1Ref` と `fY1Ref` から会計四半期を導出するロジック（NVDA: 2026年4月期末 → 2027-Q1）は
NVDAとADNTでしか実データ確認をしていません。他の非12月決算銘柄での検証は未実施。

### ⑥ E2Eは未実施

`/hawkeye-run` を含む実データでの通し実行はまだ行っていません。**現時点で「本番で動く」
とは言えません。** 566件のテストが保証しているのは、オフラインで再現できる範囲の挙動です
（2026-08-02 の反省：「348件緑」を完了として報告したが本番DBには新テーブルが1つも
無かった、と同じ轍を踏まないため明記します）。

### ⑦ 文字化けするEW応答がある

AMDの `summary` には UTF-8 として不正なバイト列（引用符）が含まれ、置換文字になります。
数値とガイダンス節の抽出には影響しませんが、`source_excerpt` にそのまま入ると
日本語レポートに文字化けが出る可能性があります。未対処。
