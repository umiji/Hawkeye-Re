# DEBUG用UIの使い方

リポジトリ直下で、これだけです。

`.venv\Scripts\python.exe debug\server.py`

localhost（127.0.0.1）での待ち受けとブラウザの自動起動まで込みなので、URL を指定する必要はありません。勝手に `http://127.0.0.1:8765/` が開きます。ブラウザを開かせたくないときだけ `--no-open` を付けてください。止めるのは `Ctrl+C` です。

## 2点だけ注意があります。

### リポジトリ直下から起動してください。
 APIキーはシェルの環境変数ではなく、リポジトリ直下の `.env.local` から読んでいます。別のディレクトリから起動すると、キーが見つからず「FINNHUB_API_KEY が読めない」というエラーが画面に出ます。

### 待ち受けアドレスは変えないでください。 
`--host` で変更はできますが、既定の 127.0.0.1（このPCの中からしか繋がらないアドレス）にしてあるのは意図的です。ここを `0.0.0.0` 等にすると、同じネットワーク上の他の端末から、あなたのAPIキーを使って取得した結果が見えてしまいます。

## 使い方
上の枠にティッカーを入れて「取得」。URL の末尾に `#AAPL` のように付ければ直接その銘柄で開くので、気になる銘柄のリンクを控えておくこともできます。ポートを変えたいときは `--port 9000` のように指定してください。
