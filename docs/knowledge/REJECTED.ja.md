# 二度と採用しない案

**読む契機: 何かを提案する前。** ここにある案はどれも一見もっともらしく、実際に一度は
採用しかけたものです。理由まで読まずに再提案しないでください。

| 案 | 棄却理由 | 出所 |
|---|---|---|
| Non-GAAP EPSをEDGARのXBRLから**計算**する | XBRLに標準化されたNon-GAAPタグは存在しない。Non-GAAPは**読む**だけ | 2026-08-02(a) |
| 「Yahooが正しく、Finnhubが誤り」という単純化 | BJRI・CDNAでは**両ソースとも調整後の値を返して一致**した。割れるのは会社が調整後EPSを公表しておらずGAAPに大きな一時要因がある場合だけ。逆にINVHではFinnhubが1行の中でFFO基準の実績とEPS基準の予想を比べていた | 2026-08-02(a) |
| 「構造化データだけで足り、発表文の読み取りは不要」 | AAPLの一時要因は売上総利益の**中**にあり、営業外損益の欄には一切現れなかった。文章にしか書かれていない | 2026-08-02(a) |
| 実績値の食い違いを**EDGARのXBRLだけ**で決着させる | XBRLが確定させるのは「提出書類上のGAAP EPSはどちらか」であって「コンセンサスがどちらの基準か」ではない。AAPLはXBRLが2.02を裏付ける一方、市場予想1.89は調整後基準で、正しい比較対象は1.91 | 2026-08-02(d) |
| 実績値の不一致しきい値(2%)を緩める | 2%は実測分布の谷から取った値(丸めの0.9%・1.1%の次が2.9%)。緩めることは「基準の違う数字を承知で比べる」ことと同義 | 2026-08-02(a)(d) |
| Finnhubの重複行のうち**Yahooと一致する方**を採る | 一致は正しさの証拠ではない。「もっともらしい方を選ぶ」という、この仕組みが排除するために存在する判断そのもの | 2026-08-02(b) |
| コンセンサス行を**上書き更新**する(1四半期1行) | 判断記録は行のIDだけを持つ設計なので、上書きすると**事前登録した推奨が後から別の数値を指す**。しかも記録上は何も起きていないように見える | 2026-08-02(b) |
| 決算実績の行を**深さの更新**で上書きする | 同上(判断がIDで指す)に加え、「見ていない」と「見たが何も無かった」の区別が消える。深さごとに**行を追加**する | 2026-08-02(c) |
| ランキングを生のサプライズ率で行う | 分母が小さいほど勝つ。2026-08-01の実行は+6958%・+5194%・+3459%が上位を占め、ほぼREIT(GAAP EPSがほぼゼロ) | 2026-08-01(b) |
| 銘柄コードを記録の主キーにする | 上場廃止後に再利用され、社名変更でも変わる。**別会社の履歴が静かに1本に混ざり**、生存者バイアスの分析が壊れる。主キーはSEC登録番号(CIK) | 2026-08-02(b) |
| 落選候補・未検証候補を「記録せず捨てる」 | 記録が無いと「見ていない」と「見て落とした」が同じに見える。落選は理由つきで残す | 2026-07-29 |
| 実績値が食い違う柱を、**小さい方が下回ったからといって下振れ**として減点する | 上振れと下振れは対称ではない。小さい方での上振れは大きい方でも上振れ(確定)だが、小さい方での下振れは大きい方について何も言わない——特別損失を計上した会社はAAPLと逆向きに同じ差が出る。減点すると「どちらが比較可能か分からない」というこちらの都合が「成績が悪かった」と読まれる。下振れは**大きい方でも下回るとき**にのみ成立 | 2026-08-03(b) |
| 発表文の読み取り待ちを、重複排除の**免除だけ**で次回に引き継ぐ | 走査期間は前回実行日基準で前に進むので、数日空けばその決算はカレンダーの問い合わせ範囲から外れる。免除だけでは足りず、**名指しで問い合わせ直す**必要がある | 2026-08-03(b) |
| EWの反映が遅いIPO直後銘柄(SPCX)を **Finviz** で補う | Finvizが出すのは**サプライズ率だけ**で実績と予想が分離できず、その率が何に対する比か(どのベンダーのコンセンサスか、GAAPか調整後か)も不明。物差しの出所が分からない数字がスコアの根拠になり、EW自身のサプライズを審査から外した判断と矛盾する。決定打は**ガイダンスが取れない**こと——ガイダンスはEWのサマリ文にしか無いので、他ソースで拾った銘柄は3本柱の1本が構造的に空のまま審理に入る。Finnhubでも事情は同じなので、論点は「どのソースを足すか」ではなく「EW以外の組で測った銘柄を候補に入れてよいか」という方針判断ひとつ | 2026-08-06 |
