## 数値ソースの信頼性(2026-08-02(a))

**母集団**: 2026-07-27〜31の決算カレンダー983行・実績のある731銘柄から、アルファベット順に
14件ごとに抜き取った50銘柄。**検証したい選別条件そのものでは絞り込んでいません**
(絞り込むと選別が拾った銘柄だけを見ることになり、結論が循環するため)。

| 測定項目 | 結果 |
|---|---|
| 実績EPSが2ソースで食い違う | **12/48 = 25%**(1セント差の丸め2件を除くと21%)。食い違いは両方向 |
| どちらを信じるかで5%選別の合否が反転する | **9/47 = 19%** |
| うち**実績値は完全に一致**していたもの | **6/9**。原因はコンセンサス側。4件(TBBK/PCAR/CARR/TRS)は予想が1〜2%違うだけで境界をまたいでおり、実績値をどう精密化しても救えない |
| 翌日までにEDGARに10-Q/10-Kがある | **37/50 = 74%**。無い26%は銀行・保険・REIT・本決算期 |
| Finnhubの**売上**実績が提出書類と一致 | **22/22**(比較可能だったすべて) |

**しきい値は発明せず、分布の切れ目から取りました。** コンセンサスの食い違い率は
0.28%〜3.50%に47件中34件が固まり、次は5.18%まで飛びます。実績値の食い違いも、
丸め(0.9%・1.1%)の次が2.9%で間が空いています。この2つの谷が **5%(予想)** と
**2%(実績)** の根拠です。

## Yahooの予想エンドポイントは決算後に1期ズレる(2026-08-02(d))

AMZNのQ2発表から3日後に取得すると、当四半期を指す行(`0q`)は **1.956**。しかし
その決算が実際に比較された予想は **1.83** でした。同じ行の前年比成長率は **+0.3%** で、
242%成長したQ2ではなく**Q3の姿**です。

→ 期ラベルは「**今日から見た四半期**」であり、決算後の取得値はその決算の予想を含みません。
**ガイダンスの比較対象としてのみ**使えます(進行中の四半期こそガイダンスの対象期間)。
これが事前登録を必要とする最も強い根拠です。詳細は
`docs/design/MASTER_OVERVIEW.ja.md` §5.3(8)。
